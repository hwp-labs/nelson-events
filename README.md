## Setup

```sh
git clone https://github.com/hwp-labs/nelsons-event-planning.git
cd nelsons-event-planning

pnpm install
pnpm run dev

# - Local:  http://localhost:3000
# - Live:   https://nelsonseventplanningcorp.com
```
